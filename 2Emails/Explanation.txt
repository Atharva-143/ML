### Step 3: Preprocessing the Dataset

The `Email No.` column is removed because it is an identifier rather than an email-content feature.

The `Prediction` column is converted into numerical format using `pd.to_numeric()`.

Records with missing target values are removed, and the target is converted to integer format.

The input features and target are separated:

* `X` contains the input features.
* `y` contains the target labels.

Missing values in the input features are replaced with zero using `X.fillna(0)`.

After preprocessing:

* Input features: 3,000

### Step 4: Splitting the Dataset

The dataset is divided into training and testing sets using `train_test_split()`.

The notebook uses:

* `test_size=0.2`
* `random_state=42`
* `stratify=y`

The dataset is divided as follows:

* Training records: 4,137
* Testing records: 1,035

Approximately 80% of the records are used for training, and 20% are used for testing.

`random_state=42` makes the split reproducible.

`stratify=y` preserves approximately the same proportion of spam and non-spam emails in both sets.

**Purpose:** The training data teaches the models, while the testing data evaluates their performance on unseen records.

### Step 5: Feature Scaling

The notebook uses `StandardScaler()` to standardize the numerical features.

Feature scaling is important because the KNN algorithm uses distances to identify the nearest neighbours. SVM can also be affected by differences in feature scales.

The scaler learns the scaling parameters from the training data and applies the same parameters to the testing data.

The training data is transformed using `fit_transform()`, while the testing data is transformed using `transform()`.

This avoids using information from the test data to calculate the scaling parameters.

**Purpose:** Feature scaling helps KNN and SVM work effectively with numerical features.

### Step 6: Implementing K-Nearest Neighbors (KNN)

K-Nearest Neighbors is a supervised machine learning algorithm used for classification.

It classifies a new data point based on the classes of its nearest training points.

The notebook creates the classifier using:

`KNeighborsClassifier(n_neighbors=5)`

The value `n_neighbors=5` means the algorithm considers the five nearest neighbours.

The model is trained using `fit()` and predicts the classes of the test data using `predict()`.

The predictions are stored in `y_pred_knn`.

The notebook calculates accuracy and displays the classification report and confusion matrix.

**How KNN works:**

1. Select a new email to classify.
2. Calculate its distances from training emails.
3. Identify the five nearest neighbours.
4. Count the class labels of those neighbours.
5. Assign the class with the majority vote.

If the majority of the selected neighbours belong to the spam class, the email is classified as spam.

### Step 7: Implementing Support Vector Machine (SVM)

Support Vector Machine is a supervised machine learning algorithm used for classification.

It finds a decision boundary that separates different classes.

The notebook uses:

`SVC(kernel="linear", random_state=42)`

The linear kernel specifies that the model uses a linear decision boundary.

The model is trained using `fit()` and predicts the classes of the test emails using `predict()`.

The predictions are stored in `y_pred_svm`.

The notebook then displays the accuracy, classification report, and confusion matrix.

**How SVM works:**

1. Takes the training emails and their class labels.
2. Learns a decision boundary separating spam and non-spam emails.
3. Uses the learned boundary to classify test emails.
4. Evaluates the predictions against the actual labels.

SVM aims to find a separating boundary with a large margin between the classes.

### Step 8: Evaluating the Models

The notebook evaluates both models using four metrics.

#### A. Accuracy

Accuracy measures the proportion of all predictions that are correct.

Formula:

Accuracy = Correct Predictions / Total Predictions

Higher accuracy generally indicates better overall classification performance.

#### B. Precision

Precision measures how many emails predicted as spam are actually spam.

Formula:

Precision = TP / (TP + FP)

High precision means fewer non-spam emails are incorrectly classified as spam.

#### C. Recall

Recall measures how many actual spam emails are correctly identified.

Formula:

Recall = TP / (TP + FN)

High recall means fewer spam emails are missed.

#### D. F1 Score

The F1 score is the harmonic mean of precision and recall.

Formula:

F1 Score = 2 × (Precision × Recall) / (Precision + Recall)

It balances precision and recall in a single metric.

Here:

* TP = True Positive
* FP = False Positive
* FN = False Negative

In this practical, the positive class is spam, represented by label 1.

### Step 9: Comparing KNN and SVM

The notebook creates a Pandas DataFrame containing the evaluation results of both models.

The comparison includes:

* Accuracy
* Precision
* Recall
* F1 Score

This table makes it easier to identify which classifier performs better.

A model should not be selected using accuracy alone. Precision, recall, and F1 score are also important, particularly when detecting spam emails.

### Step 10: Visualizing Confusion Matrices

The notebook creates two heatmaps using Seaborn.

One heatmap represents KNN, and the other represents SVM.

The confusion matrix compares actual labels with predicted labels.

The matrix uses the following order:

* First row and column: Not Spam (0)
* Second row and column: Spam (1)

The four possible outcomes are:

**True Negative (TN):** A non-spam email correctly classified as non-spam.

**False Positive (FP):** A non-spam email incorrectly classified as spam.

**False Negative (FN):** A spam email incorrectly classified as non-spam.

**True Positive (TP):** A spam email correctly classified as spam.

The heatmaps help us understand the types of errors made by each classifier.

### Step 11: Comparing Accuracy Using a Bar Chart

The final cell creates a bar chart comparing the accuracy of KNN and SVM.

The X-axis represents the models, and the Y-axis represents their accuracy.

The chart provides a visual comparison of overall classification performance.

The model with the higher accuracy makes a larger proportion of correct predictions on the test dataset.

However, precision, recall, and F1 score should also be considered before choosing the better spam detection model.

## 7. Common Errors and Their Solutions

### Error 1: ModuleNotFoundError

Example:

`ModuleNotFoundError: No module named 'sklearn'`

**Reason:** A required Python library is not installed in the active environment.

**Solution:** Open Command Prompt and execute:

`python -m pip install pandas numpy matplotlib seaborn scikit-learn`

After installation, restart the notebook kernel if necessary.

If the error continues, check whether Jupyter is using the same Python environment where the libraries were installed.

### Error 2: FileNotFoundError

Example:

`FileNotFoundError: [Errno 2] No such file or directory: 'emails.csv'`

**Reason:** Python cannot find the dataset in the current working directory.

**Solution:**

1. Check that the file is named `emails.csv`.
2. Place it in the notebook's working directory.
3. Alternatively, provide the correct full file path.

For example:

`df = pd.read_csv(r"C:\Users\athar\Downloads\Codes\ML\emails.csv", encoding="ISO-8859-1")`

Replace the example path with the actual location of your dataset.

### Error 3: KeyError: 'Prediction'

**Reason:** The dataset does not contain a column named `Prediction`, or the column has a different name.

**Solution:**

Run:

`print(df.columns.tolist())`

Check the column names and make sure the expected dataset has been loaded.

If the target column has a different name, the code must use the correct name.

### Error 4: NameError

Example:

`NameError: name 'X_train_scaled' is not defined`

**Reason:** A required cell has not been executed, or the notebook kernel has restarted.

**Solution:** Execute the notebook cells sequentially from the beginning.

You can also use **Kernel → Restart Kernel and Run All Cells** to execute the notebook from scratch.

### Error 5: ValueError During Training

**Reason:** The input data may contain invalid values, unexpected target labels, or non-numeric features.

**Solution:**

Check the feature types and missing values:

`print(X.dtypes.value_counts())`

`print(X.isnull().sum().sum())`

Check the target distribution:

`print(y.value_counts())`

Ensure that the input features are numerical and the target contains the expected labels 0 and 1.

### Error 6: KNN or SVM Takes Too Long

**Reason:** The dataset contains 3,000 input features, so calculating distances or training SVM may require significant processing time.

**Solution:**

* Wait for the cell to finish.
* Avoid repeatedly running the same cell while it is executing.
* Close unnecessary applications if the computer has limited resources.
* If the kernel is unresponsive, interrupt execution and investigate the issue.

The practical uses a linear SVM, which can take time to train on a dataset with many features.

### Error 7: Cells Run Out of Order

**Reason:** A variable such as `df`, `X`, `y_pred_knn`, or `results` has not been created in the current kernel session.

**Solution:** Run the cells in the correct order, starting with the imports and dataset-loading cells.
