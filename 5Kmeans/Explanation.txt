## 3. Theory

### What is Clustering?

Clustering is an unsupervised machine learning technique that groups similar data points into clusters.

Data points within the same cluster are generally more similar to each other than to data points in other clusters.

Clustering does not require predefined target labels.

In this practical, we group sales records using their numerical features to identify patterns in the data.

### What is K-Means Clustering?

K-Means is an unsupervised machine learning algorithm that divides data into K clusters.

Each cluster is represented by a centroid, which is the mean position of the points belonging to that cluster.

**Working of K-Means:**

1. Choose the number of clusters, K.
2. Initialize K cluster centroids.
3. Assign each data point to its nearest centroid.
4. Recalculate the centroids based on the assigned points.
5. Repeat the assignment and centroid calculation steps until the clusters stabilize or the algorithm reaches its stopping condition.

In this practical, we use K = 3, so the algorithm creates three clusters.

### What is Hierarchical Clustering?

Hierarchical Clustering creates a hierarchy of clusters based on the similarity or distance between data points.

We use **Agglomerative Hierarchical Clustering**, which follows a bottom-up approach.

**Working of Hierarchical Clustering:**

1. Initially, treat every data point as a separate cluster.
2. Calculate the distances between clusters.
3. Merge the closest clusters.
4. Repeat the merging process until the desired number of clusters remains.

In this practical, we use three clusters and Ward linkage.

### What is the Elbow Method?

The Elbow Method helps estimate a suitable number of clusters for K-Means.

It calculates the Within-Cluster Sum of Squares (WCSS), also known as inertia, for different values of K.

WCSS measures the sum of squared distances between data points and their assigned cluster centroids.

$$
WCSS=\sum_{i=1}^{K}\sum_{x\in C_i}
\|x-\mu_i\|^2
$$

Where:

* K = Number of clusters.
* \(C_i\) = Data points belonging to cluster i.
* \(\mu_i\) = Centroid of cluster i.
* \(x\) = A data point.

As K increases, WCSS generally decreases. We look for an elbow in the graph where the improvement begins to slow down.

This point suggests a suitable number of clusters.


### Step 6: Calculate WCSS using the Elbow Method

```python
wcss = []

for k in range(1, 11):
    model = KMeans(
        n_clusters=k,
        random_state=42,
        n_init=10
    )

    model.fit(X_scaled)
    wcss.append(model.inertia_)
```

This loop tests cluster counts from 1 to 10.

For each value of K:

* A K-Means model is created.
* The model is fitted to the scaled data.
* `model.inertia_` returns the WCSS value.
* The value is stored in the `wcss` list.

The parameter `random_state=42` makes the initialization reproducible, while `n_init=10` runs multiple centroid initializations and keeps the best result.

### Step 7: Plot the Elbow graph

```python
plt.figure(figsize=(8, 5))

plt.plot(range(1, 11), wcss, marker="o")

plt.xlabel("Number of Clusters (K)")
plt.ylabel("WCSS (Inertia)")
plt.title("Elbow Method for Optimal K")
plt.xticks(range(1, 11))
plt.grid(True)

plt.show()
```

The graph displays the number of clusters on the X-axis and WCSS on the Y-axis.

As K increases, WCSS decreases because the data points are assigned to more clusters.

We examine where the decrease starts becoming less pronounced to estimate a suitable K.

**In this practical, K = 3 is used for the subsequent clustering steps.**

## 8. Advantages

### K-Means

1. Simple to understand and implement.
2. Efficient for many numerical datasets.
3. Produces cluster centroids that help summarize groups.
4. Works well when clusters are reasonably compact and separated.

### Hierarchical Clustering

1. Shows relationships between clusters through a hierarchy.
2. A dendrogram helps visualize the merging process.
3. Does not require random centroid initialization.
4. Can reveal nested grouping structures.

## 9. Limitations

### K-Means

1. The number of clusters must be chosen beforehand.
2. Results can depend on initialization.
3. Sensitive to feature scaling and outliers.
4. May not work well for irregularly shaped clusters.

### Hierarchical Clustering

1. Can be computationally expensive on large datasets.
2. Early merging decisions are not normally reversed.
3. Results depend on the selected linkage method and distance measure.
4. The dendrogram can become difficult to interpret when many observations are included.

## 10. Common Errors and Solutions

### Error 1: FileNotFoundError

**Cause:** Python cannot find `sales_data_sample.csv`.

**Solution:** Keep the CSV file in the notebook's working directory or provide the correct file path.

### Error 2: UnicodeDecodeError

**Cause:** The CSV file contains characters that cannot be decoded using the selected encoding.

**Solution:** Try loading the file with `encoding="latin1"`, as done in this practical.

### Error 3: KeyError when selecting columns

**Cause:** A column name in the code does not match the dataset.

**Solution:** Run `print(df.columns.tolist())` and check the exact column names.

### Error 4: ValueError while fitting the clustering model

**Cause:** The input may contain missing or non-numerical values.

**Solution:** Select numerical features, handle missing values, and scale the data before clustering.

### Error 5: Clusters appear different in the two plots

**Cause:** K-Means and Hierarchical Clustering use different clustering procedures.

**Solution:** This is normal. Both methods can assign the same record to different clusters.
